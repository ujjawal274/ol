🔄 LeetCode #136 — Single Number

1️⃣ Problem ka Core Logic

Array ke har element ko XOR (^) karo.

Jo numbers 2 baar aaye hain, woh XOR mein cancel ho jaate hain,
aur jo number sirf 1 baar aaya hai wahi final result mein bach jaata hai.

Example:

nums = [4, 1, 2, 1, 2]

0 ^ 4 ^ 1 ^ 2 ^ 1 ^ 2

        ↓

1 ^ 1 = 0
2 ^ 2 = 0

        ↓

Final Answer = 4


2️⃣ Important Concept / Pattern

XOR + Running Result + O(1) Extra Space


Important XOR Rules:

a ^ a = 0
a ^ 0 = a


Code Pattern:

result = 0

for num in nums:
    result = result ^ num

return result


Important Variables:

nums   → input list

num    → current element of nums

result → ab tak process hue elements ka XOR

0      → starting / neutral value


O(1) Extra Space:

Hum koi new list, dictionary ya set nahi bana rahe.

Sirf fixed variables use ho rahe hain:

result
num

Isliye:

Extra Space = O(1)


3️⃣ Similar Problem mein Logic Kaise Identify Karna Hai?

Agar question mein:

- Har element 2 baar aa raha ho
- Sirf ek element single ho
- Single element find karna ho
- Extra Space O(1) required ho

toh XOR pattern immediately socho.


Quick Identification Pattern:

"Every number appears twice, except one"

                ↓

              XOR

                ↓

Duplicate pair cancel

                ↓

a ^ a = 0

                ↓

Single number remains


🧠 Core XOR Idea:

0 ^ ANY_NUMBER = SAME_NUMBER

a ^ a = 0

Isliye hum:

result = 0

se start kar sakte hain.


Final Code:

class Solution:
    def singleNumber(self, nums):

        result = 0

        for num in nums:
            result = result ^ num

        return result
